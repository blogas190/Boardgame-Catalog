This is an application for cataloging your board games and their play sessions

Current version does not store data, it is more of a test on how to build such an application

Later on this application will get updated with more features to make it more useable in general and more user-friendly

**How To Use The Application**

1. Launch the application
2. Add some board games
3. Add play sessions
4. Update/Remove games or display their information

Update Plan:

1. Add searching functionality
2. Store the data of games and play sessions
3. Store data of specific players
